JavaScript Events

The Five Basic JavaScript Events.

1. Onclick Event

Executes when the user clicks a button.

2. Ondblclick Event

Executes when the user double-clicks an element.

3. Onmouseover Event

Executes when the mouse pointer moves over an element.

4. Oninput Event

Executes whenever the user enters or changes text.

5. Onchange Event

Executes when the user changes a selected value.
